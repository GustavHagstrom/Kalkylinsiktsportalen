# Use a general renderable snapshot state

`RenderableSnapshotState` should be a general active calculation model produced by Projects, not a document component model. It should describe rows/items, hierarchy, quantities, values, `Remark` tags and replacement status; replaced rows expose both original and active replacement data so UI can explain substitutions while Reports can render the active state. Replacement rows keep their original Bidcon quantity, while `RenderedQuantity` uses the original row quantity when replaced. Renderable totals are recalculated from `RenderedQuantity` only where unit values are explicit; more complex Bidcon formula or aggregation values are preserved/exposed until their rules are known. Reports maps that state into view-defined document components such as headers, body and footers.
