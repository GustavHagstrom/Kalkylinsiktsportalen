# Kalkylinsiktsportalen

Kalkylinsiktsportalen är en .NET 10- och Blazor Server-applikation för att hämta och presentera kalkylinformation från Bidcon i anpassningsbara rapportvyer.

`README.md` är bara repoets ingång. Kanoniskt innehåll ska ägas av dokumenten i `docs/`.

## Huvuddelar

- `src/BlazorServer` - huvudapplikationen
- `src/Tests/BlazorServer.Tests` - testprojekt
- `docs` - långlivad dokumentation för domän, arkitektur, utveckling och planering

För dokumentkarta, läsordning och dokumentägarskap, se [docs/README.md](docs/README.md).
